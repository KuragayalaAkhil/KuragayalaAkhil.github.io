Professional responsive portfolio for GitHub Pages. Includes AWS Cloud Practitioner (16 Oct 2026), Azure Fundamentals AZ-900 (17 Oct 2026), Pega credentials, project cards, experience, resume and CV.

## Publish to GitHub
1. Extract this ZIP. Upload **the contents** to the root of `KuragayalaAkhil/KuragayalaAkhil.github.io` on `main` (or commit/push via Git).
2. GitHub repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
3. Verify `https://kuragayalaakhil.github.io/` before sharing.

## Optional custom domain: kuragayalaakhil.xyz
Your nameservers are delegated to Azure DNS, so create DNS records in **Azure DNS**, not GoDaddy. Follow GitHub Pages official custom-domain documentation for the current A/AAAA record values. Set `kuragayalaakhil.xyz` in GitHub Settings → Pages → Custom domain. After DNS validation, enable Enforce HTTPS. Do not add the CNAME file until you are ready to connect the domain; GitHub may create it for you.
